# The page

One self-contained HTML page. Works in light and dark. No external scripts or
fonts. Load `artifact-design` first: it owns colors as tokens, dark mode, phone
width and the `<title>` rule. This file only says what goes on the page and in
what order.

Title: the MR title, or the branch name when there is no MR. Two to four words
if it has to be cut.

## Sections, in order

1. **Header.** Title, `source -> target`, three counts (files, changed lines,
   hard parts), estimated reading time (changed lines / 25, in minutes).

2. **Start here.** Three to six bullets telling the story of the change in
   cause-and-effect order: what was needed, what was added, what it touches.
   This is the only place that talks about the whole change.

3. **Hard parts first.** Every note marked hard, as a list: file, line, the
   construct in plain words ("a chain of three calls", "a switch expression"),
   the note, and a jump link to its row. Dany reads this list before the
   files. If there are none, say "No hard parts in this diff."

4. **Files at a glance.** A table: file path, `+n / -n`, one-line purpose, hard
   count, and a "Got it" checkbox. Clicking the path jumps to the file section.

5. **One section per file**, a `<details>` element, the first one open and the
   rest collapsed. Inside, one block per hunk with a header naming where it is
   ("in `toggleSelection`, lines 40-58"). Each block is a two-column grid:

   - Left: the code line, monospace, with its line number at head, a `+` or
     `-` marker, added lines tinted green, removed lines tinted red and
     dimmed. HTML-escape the code.
   - Right: the note. A hard note carries a small "hard" badge.
   - Under 700px the two columns stack, code above note.

6. **"Got it" progress.** The per-file checkboxes from the table are saved in
   `localStorage` under a key that includes the head sha, wrapped in
   try/catch, so a half-read page can be resumed and a new push starts clean.
   A small "n of m files done" line sits next to the table.

7. **Glossary.** The jargon list from the notes, alphabetical, one line each.

8. **Not explained.** The skipped generated files, one per line, with the
   reason ("generated by freezed").

## Size

One page per diff. If the page would pass 12 MB or the size gate in step 2
split it, publish one page per feature folder and say so in the report.
